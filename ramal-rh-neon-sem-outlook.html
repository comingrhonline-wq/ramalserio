🌐 Ligar pelo link — sem Outlook e sem Bluetooth

O funcionário deve abrir o link do Ramal RH no próprio celular. Assim, ao tocar em “Ligar agora” ou “Chamar”, o discador desse celular abre com o número preenchido.

  1. Publique este arquivo como um site online e envie o endereço do site ao funcionário.
  2. O funcionário abre o endereço no Chrome do próprio celular.
  3. Ele importa a lista de contatos ou cola os números no painel.
  4. Toca em “Ligar agora” e depois no botão verde do discador.
Importante: este arquivo aberto no computador não consegue enviar números para o celular de alguém que mora longe. Para isso, não é preciso Outlook nem Bluetooth: o funcionário abre o site no próprio celular. Se todos precisarem compartilhar a mesma fila e os mesmos status em tempo real, será necessário conectar o site a uma base de dados online.
